# Pre-Pilot Compatibility Matrix

**Scope:** documentation-only baseline for existing behavior. This document does not activate a partner, production pilot, pilot window, or KPI claim. It does not propose application/schema/test changes.

**Status vocabulary:** `preserve` = existing contract must remain unchanged; `additive` = only non-breaking evidence/documentation may be added later; `blocked` = explicitly prohibited in this phase.

## Phase boundary

- `admin ops` is not an existing role. Any operational administrator must be documented as existing role `admin`.
- `additive` work is limited to later, non-breaking evidence/diagnostic surfaces; it is not implemented by T1.
- Partner activation, production-pilot execution, a two-week window, and 100 valid orders are not claimed or enabled by this baseline.
